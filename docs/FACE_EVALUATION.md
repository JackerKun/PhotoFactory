# 人物聚类评测

为了避免只凭肉眼调整阈值，可以从已经确认的人物中抽取一小批人脸，创建 CSV：

```csv
embedding_path,person_label
00012300.npy,张三
00012801.npy,张三
00022000.npy,李四
```

运行：

```bash
ai_worker/.venv/bin/python scripts/evaluate_face_clustering.py \
  /path/to/photo-library labels.csv --threshold 0.60
```

脚本只读取 `.npy` 特征，不修改照片或 `.pf` 数据库。重点关注：

- `pair_precision`：自动合并的安全性，应该优先保持较高；
- `pair_recall`：同一个人被找回的程度；
- `people_split_into_multiple_groups`：仍被拆分的人数；
- `false_merge_pairs`：不同人物被误合的数量。

建议评测集包含正脸、侧脸、低光、眼镜、口罩和跨年龄照片，并在每次更换模型或聚类规则后重复运行。

人物整理会排除同照冲突和已记录的人工分开约束。分数接近、证据不足的人脸会单独出现在「人物 → 待审核」。「人物 → 人物操作 → 高级维护 → 重建自动分组」复用已有的人脸特征，保留已命名及已人工确认的分组。「重新分析人脸」会用当前算法重新读取照片和检测人脸，适用于需要更新已有分析结果的照片库。

「人物 → 合影」可按人数或已命名人物筛选。选两人或以上即可保存为人物组合相册。相册跟随人物归属更新；开启「仅包含所选人物」后，包含额外人物或待确认人脸的照片不匹配。

「后台任务 → AI 运行信息」显示实际加载的模型后端，以及最近一批的解码、检测、特征提取和预览复用情况。各阶段耗时是并行任务的累计值，整批耗时另列。检测会复用尺寸及方向相符的 1024px 缓存预览；提取特征仍从源图对齐取样。未命中预览时可直接分析照片。速度取决于 GPU、照片格式、预览命中率和人脸数量。
